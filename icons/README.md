# AfterWatch icon

The chosen AW monogram combines the project initials with a play triangle inside the A. Its palette uses charcoal `#14171b` and mint `#87d9ab`.

- `afterwatch.svg` is the editable vector source. Its shapes are paths, so rendering does not depend on installed fonts. No bitmap is embedded.
- `icon-16.png`, `icon-32.png`, `icon-48.png` and `icon-128.png` are the Chrome icon exports. Each retains transparent corners around the rounded background.
- The manifest references these local PNGs for the extension and toolbar icon.

The vector source and exports are included under the repository's MIT license and shipped in the v1.4.0 ZIP.
